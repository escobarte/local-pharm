# BRAND — Local Pharm

Палитра: вариант 3 · Navy (выбран 2026-11-20).

## Цвета

| Токен | HEX | Где |
|---|---|---|
| `navy` | `#122056` | Основной текст, тёмные кнопки, фон экрана входа, активный пункт меню |
| `accent` | `#00B5AA` | Кнопка «+», выбранные элементы, иконки мест хранения, чекбоксы |
| `bg` | `#FAFAFD` | Фон экранов |
| `surface` | `#FFFFFF` | Карточки, поля ввода, нижнее меню |
| `tint` | `#EEEFFD` | Плашки-теги, заглушки фото, неактивные сегменты |
| `border` | `#DDDFF3` | Рамки полей и вторичных кнопок |
| `muted` | `#5A6283` | Вторичный текст, неактивные пункты меню |
| `danger-fg` / `danger-bg` | `#B42318` / `#FDECEA` | Просрочено |
| `warn-fg` / `warn-bg` | `#9A4A00` / `#FFF1E0` | Истекает в 30 дней |
| `warn-dot` | `#D97706` | Точка-индикатор «скоро» |

Правила контраста:
- На `accent` — только `navy` (текст и иконки). Белый на бирюзовом не читается.
- `accent` не использовать как цвет текста на белом (контраст ~2.6:1).
- На `navy` — белый текст.

## Типографика

- Шрифт: Inter (запасной: Helvetica, Arial, sans-serif).
- Заголовок экрана: 28 px / 700. Заголовок карточки: 24 px / 700.
- Основной текст: 15 px. Вторичный: 13 px. Подписи секций: 12 px / 600, UPPERCASE, `muted`.

## Формы

- Радиусы: поля и кнопки 12–14 px, карточки 14–16 px, теги 8 px.
- Высота кнопок и полей: 48–52 px; минимальная touch-цель 44 px.
- Иконки: линейные, stroke 1.8, 24 px. Без эмодзи.

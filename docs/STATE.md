## Решения

- 2026-11-20 — Палитра: вариант 3 · Navy. Git, push и деплой делает только владелец. Стили: Tailwind.
- 2026-11-21 — Остаёмся на Supabase (не Turso).
- 2026-11-21 — Инструменты: pnpm, Node 22.x, Tailwind v4, Next 16, TypeScript 5.9, ESLint 9, manifest background_color #FAFAFD.
- 2026-11-21 — Supabase: автоматический RLS включён, автоматический GRANT выключен (права в миграциях явно).
- 2026-11-21 — Репозиторий публичный: email, ключи и project ref в нём не хранятся.
- 2026-11-21 — Названия зон: Быстрый доступ, Основной склад, В дорогу. Зоны не редактируются.
- 2026-11-21 — Упаковке отсек обязателен, срок годности необязателен. Выход разлогинивает только текущее устройство.
- 2026-11-22 — Срок «12/2026» хранится как конец месяца. Порог «истекает» и «просрочено» считаются по дате сервера (UTC).
- 2026-11-22 — Одна карточка результата поиска — один препарат (количество суммируется, место и срок у самой срочной упаковки). Поиск выполняется в коде приложения, не в SQL (кириллица, регистр, ё = е).
- 2026-11-22 — Десктоп: боковое меню от 1024 px, одна кодовая база (Фаза 3b). Детали в BRAND и WIREFRAMES.
- 2026-11-23 — Реестр AMDM хранится в своей таблице, импорт через CSV (Table Editor), обновление повторной выгрузкой. Штрихкодов в реестре ~4% (258 из 6331), остальные запоминаются при первом добавлении. Международный поиск только openFDA, RxNorm не подключаем. Категория по ATC подставляется только для буквы C.
- 2026-11-22 — Категория коробки в базе не хранится, выводится из препаратов внутри.

## Известные ограничения

- PostgREST отдаёт не больше 1000 строк за запрос: каталог и счётчики без пагинации занизят данные при тысяче с лишним упаковок (записано в GOTCHAS).
- Десктоп: «Удалить упаковку» и «Переложить» из панели поиска ведут на полную страницу препарата (так устроены серверные действия). Пункт меню называется «Сроки», в макете «Сроки годности».
- Сканер читает только полоски EAN/UPC, не DataMatrix. Поиск «У вас дома» латиницей не находит русские названия. Русский поиск по реестру best effort («Активированный уголь» не найдётся). openFDA: лимит по IP, американский рынок. Нет фонарика и выбора камеры.
- Не сделано: фото упаковки, аватары из макета.

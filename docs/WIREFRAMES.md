# WIREFRAMES — Local Pharm

Каркасы экранов (вариант 3) лежат в `docs/mockups/` — HTML с inline-стилями, открывать как справку по составу и размерам. Мобильные макеты: ширина 390 px (`*-v3.dc.html`). Десктопные: ширина 1440 px (`*-desk.dc.html`).

## Навигация

Нижнее меню на всех экранах, кроме «Вход» и «Добавление»: Главная · Хранение · **+** (Добавить) · Сроки · Покупки.

Десктоп (от 1024 px): вместо нижнего меню боковое тёмно-синее (248 px) с теми же разделами, кнопкой «Добавить препарат» и блоком пользователя («Выйти») внизу. Экран «Вход» без меню.

## Экраны (мобильные)

| N | Экран | Файл | Состав |
|---|---|---|---|
| 01 | Вход | `Main-v3.dc.html` | Логотип, название, подзаголовок, «Войти через Google», подпись «Доступ только для двух приглашённых аккаунтов» |
| 02 | Главная | `Home-v3.dc.html` | Аватары пользователей, «Что ищем?», поле поиска + кнопка скана, блок «Внимание» (истекают / заканчиваются), сетка 9 категорий |
| 03 | Результаты | `Results-v3.dc.html` | Поле поиска, фильтр-чипы по категориям, счётчик, карточки: название, вещество, форма, бейдж (Истекает / Мало), строка места: «Коробка 1 · B2», срок, количество |
| 04 | Карточка препарата | `Medication-v3.dc.html` | Фото, название, вещество, теги (форма, категория, источник), список упаковок (место, кол-во, срок, вскрыта, «Взял 1 шт.», «Заканчивается»), показания, «Добавить упаковку» |
| 05 | Добавление | `Add-v3.dc.html` | Переключатель Скан / Поиск / Вручную; блок упаковки: количество, срок, коробка, отсек, фото; «Сохранить» |
| 06 | Хранение | `Storage-v3.dc.html` | Сводка, скан QR коробки, зоны (Быстрый доступ, Основной склад, В дорогу) с плитками коробок, «Новая коробка» |
| 07 | Коробка | `Box-v3.dc.html` | Номер, название, зона и категория; схема отсеков A1–B3 с количеством; список выбранного отсека; «Добавить сюда», «Печать QR» |
| 08 | Сроки годности | `Expiry-v3.dc.html` | Группы: Просрочено / 30 дней / 90 дней; строка: название, место, дата, действие (Выбросил / В покупки) |
| 09 | Покупки | `Shopping-v3.dc.html` | Поле добавления, «Купить» (чекбоксы с причиной), «Куплено» (кто и когда, «Разложить») |

Данные в макетах — примеры, не справочник.
